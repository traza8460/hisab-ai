# Hisab-AI Project Instructions

- **Git Push Policy**: Do NOT automatically push commits to GitHub. Only commit locally or push when the USER explicitly asks to push.
- **Commit Messages**: When asked to commit or push, always use short, concise English conventional commit messages (e.g. `feat: ...`, `fix: ...`, `docs: ...`, `refactor: ...`).
- **Security & Hygiene**: Never commit `.env`, secrets, credentials, log files (`*.log`), databases (`*.db`), or virtual environments (`.venv/`).
